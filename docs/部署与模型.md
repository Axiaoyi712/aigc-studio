# 部署与模型

## ComfyUI 与路径

本项目复用已有 ComfyUI，不分发 Python、CUDA、模型或插件。当前图适配 Z-Image、FLUX Klein 和 MiniMax H3 的对应节点契约。请先确认原生 ComfyUI 能运行匹配的图，再使用创作台。

一键启动要求目录中同时存在 ComfyUI/main.py 和其上级目录的 python_embeded/python.exe。普通 Python 安装方式可手动启动 ComfyUI，再运行 npm start。config.json 中 comfyRoot 使用绝对路径；comfyUrl 必须指向本机 HTTP 服务。

## 工作流模型清单

仓库下的 model-manifest.json 从五份工作流自动提取，列出 UNET、CLIP、VAE 与 LoRA 文件名。模型名称必须与本机 /object_info 的可选项一致；可在 workflows/ 中按已安装模型修改。节点缺失时，“本机能力检查”和提交前校验会提示。不要仅凭相同文件扩展名替换不同模型架构。

H3 首帧视频采用 I2V/FL2VA 权重；Ref2VA 需独立权重 minimax_h3_ref2va_pruned_w6a8.safetensors、MiniMaxH3ReferenceToVideo 节点，并在 config.json 将 enableRef2VA 设为 true。默认关闭；它以多张图作为参考，不会把参考图硬锁成第一帧。

## Python 媒体依赖

媒体拼接、尾帧提取、视频信息读取和 ZIP 处理使用 ComfyUI 便携版 Python。需要 av、numpy、Pillow。已有环境中先验证导入，不要为启动创作台随意升级 PyTorch 或 CUDA。

## 提示词库

仓库仅提供两条原创入门示例。复制 library/catalog.example.json 为 library/catalog.json 即可使用。自己的文档可通过导入脚本生成索引：

~~~powershell
python -m pip install -r requirements-prompts.txt
python scripts/import-prompt-library.py "D:/自己的提示词目录" "data/prompt-catalog.json"
~~~

本地文档按资料读取，不执行其中的指令。页面内刷新还依赖本机 LOCALAPPDATA/Programs/Python/Python39/python.exe；其他 Python 布局请使用上方手动导入命令，并重启创作台读取索引。可在 config.json 增加 promptLibraryRoot 指向原始资料目录。

## 可选文字助手

在 config.json 的 assistant 中配置 llama-server.exe 的 serverPath、聊天 GGUF 的 modelPath、baseUrl 与 model 名称。两条路径为空时无法自动启动助手。默认使用本地 CPU 推理；文字结果先生成草稿，需人工查看并应用。未配置时可继续手工制作图片和视频。

## 分辨率、参考与速度

参考数量上限是工作台的输入规则，不代表任意显卡在高分辨率下都能承受 20 张参考。实际显存与耗时需在本机验证。先从少量参考、短时长、省显存档开始。H3 当前视频图与图片图分别设置分辨率；最终成片画布放大不会增加源视频细节。


## 高清精修模型

从作者官方Release下载 [RealESRGAN_x2plus.pth](https://github.com/xinntao/Real-ESRGAN/releases/download/v0.2.1/RealESRGAN_x2plus.pth)，放入 <comfyRoot>/models/upscale_models/。不随仓库上传，程序不自动下载。

- 文件大小：67,061,725字节。
- 本次验收文件SHA-256：49fafd45f8fd7aa8d31ab2a22d14d91b536c34494a5cfe31eb5d89c2fa266abb。
- 使用已有ComfyUI Python中的PyTorch、spandrel，以及requirements-media.txt列出的依赖；不需要为了这个功能升级现有CUDA或PyTorch。
- 需要可用NVIDIA CUDA。模型逐帧、分块处理，生成后台先释放模型缓存；在原生ComfyUI页面手动提交的新任务不受工作台互斥控制，请勿同时运行。

本次RTX 5060 Laptop约8GB显存验收：73帧、24fps、512×320原片输出1920×1080，约38秒；音频包一致。该速度只代表此片段，不是所有视频的耗时承诺。人脸与复杂动作片段仍需人工检查。


## 角色合成（v0.11.0）

角色合成复用已有 FLUX Klein 4B FP8 多参考工作流，无需新装大模型或姿势插件。角色、服装、姿势、场景由独立槽位和提示词分工，参考编号与实际工作流输入顺序一致。它属于参考引导，不是逐关节的 ControlNet 约束。

公共参考原图和运行索引不随本仓库分发。第一次下载时可以直接上传自己的图片，或将逐张合法取得的参考图导入“我的参考”。程序不会自动批量下载姿势、服装原站。自备 CC0 公共参考库时，可在运行数据目录的 reference-library.json 中登记条目；文件路径必须在 <comfyRoot>/output/AIGC项目/公共素材库/参考图库 内。

8GB 显存建议先使用 2～3 张必要参考和约百万像素画幅。开发机 RTX 5060 Laptop 本次三图、四图测试均输出 768×1024，分别约 23.82 秒、19.46 秒；仅代表该环境与测试输入，不是固定耗时保证。2K 会增加显存与耗时。
