# 白膜／深度视频制作

在左侧“视频创作”选择“白膜驱动视频”。先选择或新建保存项目，在左侧导入与设置片段，右侧预览素材，最后创建镜头。本功能目前针对已经处理好的深度视频，使用 H3 FL2VA＋Fun ControlNet Union；普通彩色视频不会自动进行人体动作捕捉或深度提取。

## 从任意文件夹导入

推荐在资源管理器右键视频，选择“复制文件地址”，粘贴到“关联视频完整路径”，点击“读取视频”。支持中文文件名、空格和不同盘符。关联方式只记录原位置，不复制整个视频；原文件移动、删除或修改后，需要重新关联。

也可点击文件选择框，从其他文件夹直接选视频，再点“导入视频”。这种方式会保存一份到当前项目的“驱动素材”，原文件不会修改。浏览器无法从普通文件选择器取得可靠的本机完整路径，因此这两种方式分开提供。

识别结果包含宽高、时长、帧率和预览。支持 MP4、MOV、MKV、WEBM、AVI；能否解码以实际文件为准。路径关联无1GB上传限制，文件选择上传最大1GB。视频不超过30分钟。

## 建立镜头并生成

1. 在“资产定稿”保存人物、场景、道具参考，设置项目角色并勾选其参考图片。建议先用一个人物和一至三张清晰参考试做。
2. 关联深度视频，预览后填写开始、结束秒数。单镜头最多5.17秒，建议先试约3秒。也可点击“整段自动拆分”，完整覆盖原片，不会静默只取开头。
3. 在“生成范围”选择片段或整段自动拆分，再选择画质档位：“原生高清”以至少720p的尺寸进行模型采样；“快速生成＋自动AI精修720p”先生成较小原片，再用本地Real-ESRGAN精修。默认原生高清，更慢。
4. 点击“创建N个镜头”，按成功提示选择“继续：设置人物与场景”或“已有参考，去编辑镜头”。镜头已绑定其深度片段，自动继承项目角色。调整本镜头出场人物与场景、道具参考，填写总提示词或细项。
5. 先生成首帧，检查构图、姿势、人物身份与服装，选择并确认满意版本，再生成视频。也可“一键生成首帧＋视频”，它会自动确认新首帧，建议熟悉效果后再使用。
6. 在“驱动／结果同步对比”检查动作和构图。正式视频不足所选清晰度时会自动精修；完成后项目自动选用高清版，原片保留，可切换和对比。
7. 到“成片归档”检查选段、声音、成片画布，再拼接导出。

深度视频负责动作与空间，人物身份主要由生成并确认的首帧负责。每镜的白膜首帧占一张FLUX参考位置，因此其他角色、场景和道具合计最多19张。复杂手指、遮挡、嘴型、多角色交叉运动不能保证准确；源视频叠字、水印可能被带入生成结果，优先使用干净深度素材。

## 720p与性能

720p在这里表示正式视频短边至少720像素：16:9横版一般为1280×720，9:16竖版为720×1280，3:4为720×960。H3原生采样需满足32像素网格，因此原生尺寸可能略高，例如3:4为768×1024。

原生高清与AI精修不同：精修不会恢复原片不存在的真实细节，也不会保证动作或人物完全一致。界面会标注原生尺寸、AI精修目标和实际成片尺寸。只有输出实测达到门槛才算高清完成，精修失败会保留原片并提示重试。

本机验收：RTX5060 Laptop 8GB、约32GB内存，3:4深度片段约2.8秒，73帧模型序列裁掉补齐尾部后保留68帧、24fps。原生768×1024真实生成成功，用时约10分钟；快速路径384×512原片自动精修为720×960，连同首帧生成约3.5分钟。耗时只供该样本参考，不代表所有片段、画幅和时长均已验证。

白膜镜头采用绑定片段的时长和画幅，不采用普通镜头的默认每镜时长。深度片段不继承原视频声音；需要台词、音乐时在后期另配。

## 文件和归档

生成结果仍统一保存在ComfyUI的 `output/AIGC项目/<项目>/`。驱动短片缓存放在本项目“驱动素材”；兼容首帧PNG放在ComfyUI input的aigc-studio/drivers下。不会为每镜另存一份完整原视频。

完整项目ZIP归档会打包引用的驱动原视频与短片段，便于换电脑恢复；这是显式归档副本，会占相应磁盘空间。仅复制创作台源码不能迁移这些素材。

## 模型与节点

额外模型放入 `ComfyUI/models/model_patches/`：

`minimax_h3_fun_controlnet_union_pruned_int8_convrot.safetensors`

大小2,296,635,360字节；SHA256：`9c645c0a308c8af361efd43b409710f6f8fec0db297c29503e141a84991fed0c`。

使用现有H3 FL2VA量化主模型、Qwen3VL编码器和H3 VAE；需要原生节点LoadVideo、GetVideoComponents、ModelPatchLoader、MiniMaxH3FunControlNetApply、ImageFromBatch。没有这些节点时会在提交前提示。原有快速视频、图生图流程保留。
