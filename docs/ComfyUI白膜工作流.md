# 在ComfyUI中生成白膜驱动视频

ComfyUI左侧“工作流”中打开“白膜视频”文件夹；新节点安装后刷新一次网页。

## 01：白膜＋人物场景，一键生成首帧和视频

1. 在“①白膜视频路径与片段”粘贴原视频完整路径，例如 `E:\视频\深度动作.mp4`；可保留资源管理器复制地址时的双引号。设置开始秒数和片段时长，建议先做约3秒。原片只读，不复制整片，也不保存中间驱动视频。
2. 在“②人物参考”和“③场景参考”选择统一output目录内已有图片。人物图负责身份、服装；场景图负责环境。白膜首帧自动作为构图和姿势参考。参考越清楚、与白膜构图越兼容，越容易得到可用结果。
3. 修改“④首帧提示词”和“⑤视频提示词”。前者描述人物和画面，后者描述动作、镜头与连续性，均可使用中文。
4. 修改两个结果节点的“文件名前缀”，例如首帧 `AIGC项目/我的短剧/镜头01/首帧/首帧`，视频 `AIGC项目/我的短剧/镜头01/视频/视频`。
5. 点击“运行”。先生成FLUX首帧，再将它与逐帧白膜深度一起送入H3，最后显示首帧与视频。

如果首帧不满意，需要先挑版本：将视频结果保存节点设为“停用（Never）”，只生成首帧；满意后使用下面的02工作流，避免每次都重做首帧。

## 02：白膜＋已确认首帧，生成视频

1. 填写同一个白膜视频路径、起点和片段时长。
2. 在“②已确认首帧”选择满意PNG的具体文件名。可选01工作流生成的首帧，也可选工作台里之前生成的任意版本；不会自动换成最新版本。
3. 修改视频提示词和保存前缀，点击“运行”。这个入口不运行FLUX、不重做首帧。

## 03：多个人物，或同一人物的多张参考

打开“03-白膜＋多人物多图参考-一键生成-720p”。默认提供人物A、人物B和场景三个图片选择节点；原生多图参考节点会自动增加空白图片接口，无需安装新节点或模型。

初始图序为：图1白膜首帧、图2人物A、图3人物B、图4场景。正面、侧面、背面的三视图设定板属于同一个角色，可以整张放入一个人物参考节点。

多个人物时，在首帧提示词里明确身份与站位，例如：

> 图2是人物A，图3是人物B，图4是场景。白膜左侧的人替换为A，右侧替换为B。分别保持各自五官、体型、发型和服装，不交换身份，不混合成同一个人。人物数量、姿态、前后关系遵循图1。

增加第三个人物或更多角度：

1. 选中“人物参考”节点，按Ctrl+C、Ctrl+V复制一个，选择它的参考图片。
2. 将新节点的IMAGE输出，连到“多图参考”最下方的空白图片接口；随后自动出现下一个接口。
3. 第一张新增参考是图5，下一张是图6。根据连入的先后顺序，在提示词里补充“图5是人物C，站在……”。

同一人物有多张参考时，明确写“图2、图5、图6都是人物A的不同角度；图3是人物B”，保留各自的站位。若图2和图3都是同一人物，请替换默认双人物的身份、站位描述，不要同时保留“A与B为不同人物”的指令。

不用某张图片时，断开其参考连线并删去对应描述；删除、重排连线后，按从上到下的图片顺序重新核对所有图号。模型按参考顺序接收图片，节点标题本身不会自动绑定角色。

本机8GB显存，建议先每人一张清楚的参考，默认先试1.6秒、原生短边768的短片，再逐步延长。更多参考和更长片段需要更多资源；4、5、20张接口与引擎参数已检查，不代表20张真人或多人动作效果已通过实机验收。

这些人物参考先用于生成首帧，视频仍通过首帧和深度白膜控制。先检查首帧是否串脸、站错位；满意后可在02中选定该首帧反复生成视频。多人遮挡、交叉动作仍可能发生身份漂移。

## 04与05：8GB显卡的快速AI高清流程

- **04-白膜多人物-快速8步-AI高清720p**：从人物与场景参考开始，生成首帧，再生成快速视频。图片编号和增加参考的方法与03一致。
- **05-已有首帧-快速8步-AI高清720p**：选择已经满意的首帧，直接生成视频，省去重复跑FLUX。首帧应与白膜片段起点和机位匹配。

本版将H3采样降至约0.25MP，使用本机已有8步加速LoRA，再以Real-ESRGAN逐帧精修，输出到所选画布。默认最终短边768，属于**AI精修高清，不是原生720p采样**。输出短边保持768即可满足至少720p；不要把该目标尺寸降低。中间低清帧仅在内存中处理，不另存低清视频。

先用默认2.33秒试跑。约5秒请填写**5.16秒**：当前24fps采样向上取整时，5.16秒对应124帧；填写5.17会变成125个有效帧，再补齐至141帧，额外增加运算与显存负担。成片按有效帧裁切，5.16秒输入实际输出124/24≈5.17秒。

模型加载、文本与白膜编码时，采样进度可能暂时显示0%；应结合后台日志和任务状态判断。GPU占用高只能说明设备繁忙，不能据此保证任务会成功。原生短边768、长片段、20步叠加时，在本机8GB显卡上曾发生后台异常退出。原生流程保留，建议先从短片段试验。

快速版优先保证可完成性与速度，细节、动作和纹理可能与20步原生版不同。逐帧AI精修不会增加原始时间采样的信息，也可能出现纹理闪烁；需要逐镜检查效果。

## 画质、速度和时长

- 默认原生短边768像素：3:4白膜生成768×1024，16:9生成约1376×768，9:16生成约768×1376。宽高自动按H3要求对齐32像素。
- 默认使用本机H3 FL2VA W6A8量化模型、基础20步、深度控制强度1、分块解码。8GB显存优先从约3秒试做；原生高清比低分辨率预览慢。
- 按视频真实时间采样到24fps，补齐到H3模型所需帧数；成片再裁掉补齐尾部。实际时长按整帧向上取整，最多多约一帧。
- 只对已经处理好的深度白膜视频进行控制。普通彩色视频不会自动提取深度、骨骼或动作。人物一致性仍取决于参考图与首帧，不能保证手指、遮挡和多角色交叉运动完全准确。
- 此工作流不继承原录像的声音，配音和音乐后期添加。

## 存储

结果只写入 `ComfyUI/output/AIGC项目/`，不生成媒体ZIP备份。读取白膜原片只使用原文件；中间深度帧在内存中处理。参考图和已确认首帧可直接选output中的原件，不需要重复上传。

直接在ComfyUI生成的结果可在ComfyUI预览及文件夹中查看；它们不会自动创建工作台项目、镜头或“我的作品”记录。要沿用工作台的角色资产、批量队列和项目管理，请继续使用工作台入口。

## 在其他安装中复用

把 `comfyui/AIGCDepthWorkflow` 放到ComfyUI的 `custom_nodes/`，把 `comfyui/workflows/白膜视频/` 中的JSON放到 `user/default/workflows/白膜视频/`，重启ComfyUI。需要本机已安装的FLUX Klein、H3 FL2VA及Fun ControlNet模型；不调用云端API，不自动下载模型。
