# 在ComfyUI中生成白膜驱动视频

ComfyUI左侧“工作流”中打开“白膜视频”文件夹；新节点安装后刷新一次网页。

## 01：白膜＋人物场景，一键生成首帧和视频

1. 在“①白膜视频路径与片段”粘贴原视频完整路径，例如 `E:\视频\深度动作.mp4`；可保留资源管理器复制地址时的双引号。设置开始秒数和片段时长，建议先做约3秒。原片只读，不复制整片，也不保存中间驱动视频。
2. 在“②人物参考”和“③场景参考”选择统一output目录内已有图片。人物图负责身份、服装；场景图负责环境。白膜首帧自动作为构图和姿势参考。参考越清楚、与白膜构图越兼容，越容易得到可用结果。
3. 修改“④首帧提示词”和“⑤视频提示词”。前者描述人物和画面，后者描述动作、镜头与连续性，均可使用中文。
4. 修改两个结果节点的“文件名前缀”，例如首帧 `AIGC项目/我的短剧/镜头01/首帧/首帧`，视频 `AIGC项目/我的短剧/镜头01/视频/视频`。
5. 点击“运行”。先生成FLUX首帧，再将它与逐帧白膜深度一起送入H3，最后显示首帧与视频。

如果首帧不满意，需要先挑版本：将视频结果保存节点设为“停用（Never）”，只生成首帧；满意后使用下面的02工作流，避免每次都重做首帧。

## 02：白膜＋已确认首帧，生成视频

1. 填写同一个白膜视频路径、起点和片段时长。
2. 在“②已确认首帧”选择满意PNG的具体文件名。可选01工作流生成的首帧，也可选工作台里之前生成的任意版本；不会自动换成最新版本。
3. 修改视频提示词和保存前缀，点击“运行”。这个入口不运行FLUX、不重做首帧。

## 画质、速度和时长

- 默认原生短边768像素：3:4白膜生成768×1024，16:9生成约1376×768，9:16生成约768×1376。宽高自动按H3要求对齐32像素。
- 默认使用本机H3 FL2VA W6A8量化模型、基础20步、深度控制强度1、分块解码。8GB显存优先从约3秒试做；原生高清比低分辨率预览慢。
- 按视频真实时间采样到24fps，补齐到H3模型所需帧数；成片再裁掉补齐尾部。实际时长按整帧向上取整，最多多约一帧。
- 只对已经处理好的深度白膜视频进行控制。普通彩色视频不会自动提取深度、骨骼或动作。人物一致性仍取决于参考图与首帧，不能保证手指、遮挡和多角色交叉运动完全准确。
- 此工作流不继承原录像的声音，配音和音乐后期添加。

## 存储

结果只写入 `ComfyUI/output/AIGC项目/`，不生成媒体ZIP备份。读取白膜原片只使用原文件；中间深度帧在内存中处理。参考图和已确认首帧可直接选output中的原件，不需要重复上传。

直接在ComfyUI生成的结果可在ComfyUI预览及文件夹中查看；它们不会自动创建工作台项目、镜头或“我的作品”记录。要沿用工作台的角色资产、批量队列和项目管理，请继续使用工作台入口。

## 在其他安装中复用

把 `comfyui/AIGCDepthWorkflow` 放到ComfyUI的 `custom_nodes/`，把 `comfyui/workflows/白膜视频/` 中的JSON放到 `user/default/workflows/白膜视频/`，重启ComfyUI。需要本机已安装的FLUX Klein、H3 FL2VA及Fun ControlNet模型；不调用云端API，不自动下载模型。
