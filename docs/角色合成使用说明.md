# 角色合成使用说明（v0.11.0）

在“图片创作”顶部选择“角色合成”。也可以从项目镜头的“候选首帧”旁点击“参考合成首帧”，自动带入项目和镜头。

## 一次生成

1. 选择当前项目和目标镜头；没有项目时可以使用“独立创作”。
2. 在“人物 A”中点击“浏览参考”，选择公共 CC0 人像或当前项目角色；也可以直接上传、拖入或粘贴图片。
3. 在“姿势／构图”中选择动作。图库按姿势分组，支持分类、搜索、视角切换、大图预览与随机选图。
4. 按需展开“服装、场景与第二位人物”。没有服装参考时沿用人物原图的服装；服装槽只作用于人物 A。添加人物 B 后必须填写双方对应关系。
5. 用一个“补充描述”输入框写表情、景别、细节和光照，选择画风与尺寸。
6. 展开“查看实际图片顺序与完整提示词”，核对各张图的用途，然后点击“生成候选图片”。不需要另外输入图片编号。
7. 在右侧选择满意的图片版本。选定项目和镜头后，点击“加入目标镜头首帧候选”，再点击“前往项目确认首帧”。
8. 在镜头中确认该版本，再生成 H3 视频。加入候选不会自动确认首帧，也不会重做已经存在的视频。

每次生成都会保留独立版本。右侧选择的历史版本不会被后台刷新自动替换为最新版本。

## 角色定稿与组合方案

- 满意的单人结果可以填写角色名称并点击“保存为项目角色定稿”。使用现有项目资产目录，之后可在项目角色中选用。
- 展开“保存／载入组合方案”，填写名称并保存。方案记录参考图片编号、用途、提示词、画风、尺寸与种子，不复制原图。
- 删除方案只移除配置；在“我的参考”中删除自定义图片则会永久删除原图，并清理相关项目、作品和方案引用。
- 自定义上传按当前项目隔离。使用“独立创作”上传的图片进入“我的参考”，不会自动显示到所有新项目中。
- 已保存方案引用的图片被移除后，会提示缺失；需要重新选择图片。

## 本机生成与效果边界

生成使用本机已有的 FLUX Klein 4B FP8 多参考工作流，不需要新装大模型或 ComfyUI 插件。

8GB 显存建议先使用 2～3 张必要参考、约百万像素输出。原生 2K 选项会显著增加显存与时间需求，界面会明确提示；并非后期放大。图片与视频任务沿用现有串行队列。

参考图通过明确用途的提示词与 ReferenceLatent 进入工作流。这是参考引导，不是 OpenPose 或 ControlNet 的逐关节硬控制，不能保证人物绝对一致。对双人身份、手指和复杂遮挡应人工选片。

## 文件与授权

所有生成媒体继续保存在配置中的 `ComfyUI/output/AIGC项目/`。指定镜头的生成结果直接保存在该镜头目录。选用为首帧或角色定稿时，引用同一原件；目录调整也会更新原有引用。

公共参考原图仅一份，位于 `output/AIGC项目/公共素材库/参考图库/`；索引位于 `aigc-studio/data/reference-library.json`。不额外生成原图备份或拼图副本。

开发机首批参考为 16 张 CC0 人像、14 组姿势的 42 张视角图、12 张现代服装和 11 张场景；这些图片及本机索引不随 GitHub 源码分发。全新下载时公共图库为空，直接上传自己的参考即可使用人物、服装、姿势与场景组合；已上传图片可在“我的参考”或对应项目中复用。

- 人像原站：<https://ai-portrait-gallery.pages.dev/>，标注 CC0-1.0；原站另请求不要原样转载整库。
- Shisei：<https://github.com/wquguru/shisei>，使用该项目明确声明为 CC0 的原创图片及其自有描述。姿势分类与中文显示名由本工作台自行整理，不复制该项目排除授权的上游姿势名称、编号目录。
- 姿势原站：<https://ai-pose-gallery.pages.dev/>；服装原站：<https://ai-costume-gallery.pages.dev/>。两者允许逐张用于作品参考，禁止批量抓取及图片数据再分发。本工作台提供原站入口，不镜像其整库。

各张公共参考保留原图地址、来源、许可、文件大小和 SHA-256。详见 `参考图库来源说明.md`。
