# 外部首帧使用说明（v0.10.1）

在其他软件或 ComfyUI 中生成的图片，可以直接成为项目镜头的首帧。

## 最短操作路线

1. 进入“镜头项目”，选择项目，打开“分镜设计”或“生成选片”，展开目标镜头。
2. 在“候选首帧”旁点击“导入／选用首帧”。
3. 点击“选择本地图片”，在浏览器打开的系统选图窗口里选择图片；也可从已有作品、项目图片中选用。
4. 检查原图尺寸及项目画幅预览，导入为候选版本。
5. 点击“确认所选首帧”。
6. 在总提示词或“动作、镜头与声音”填写视频动作，点击“用当前首帧生成视频”。不必再填写首帧画面描述。

“一键生成首帧＋视频”会重新生成首帧；如要沿用外部图片，使用“用当前首帧生成视频”。历史首帧和已有视频会保留，可以切换回旧版本，再确认使用。

## 导入方式与文件存放

- 选择本地图片／拖放：直接由浏览器打开系统文件窗口，选图后先预览，点击“加入候选首帧”才会导入。复制保留外部原文件；取消选图不会卡住弹窗，也不会导入图片。
- 按路径导入／移动：粘贴图片的完整路径，点击“读取图片”检查预览，再选择复制或移动，最后加入候选。支持文件资源管理器“复制文件地址”带双引号的路径；移动会在成功接管后删除外部原文件。读取路径时可重新选图或关闭弹窗。
- 已有作品／项目图片：直接引用工作台管理的原件；相同内容按 SHA-256 去重，不创建第二份媒体。
- 直接放入文件夹：打开目标镜头文件夹，把图片放入其“首帧”子目录。工作台空闲时通常 3～6 秒识别为候选，仍需手动确认。

接受 PNG、JPEG、WebP，单张不超过 20MB、约 4000 万像素，并检查图片能实际解码。导入后的管理原件位于 `<comfyRoot>/output/AIGC项目/` 中；文件夹里保留原图，不把裁剪预览另存一份。

若更新前的弹窗卡在“正在导入”，按 Ctrl+F5 刷新页面，再重新打开“导入／选用首帧”。只有实际上传并加入候选时才会显示“正在导入”；打开选图窗口不占用后台导入状态。

## 画幅、版本和同步

画幅预览按照当前项目的视频画幅进行居中裁剪。生成时继续使用项目的视频分辨率档位；导入 2K 图片不会自动改为 2K 视频。需要改变取景时，应先在外部调整原图，或调整项目画幅。

导入不会自动确认。确认记录绑定图片内容：改名保留版本和确认；替换图片内容会取消确认；删除文件会清理相应候选与引用。生成前还会检查文件内容，避免排队期间被替换的图片悄悄参与生成。

动作、时长调整后可以继续使用已确认的外部首帧。角色、场景、画风调整时会提醒人工核对，工作台不会强制重画已导入图片。新动作或新设置对应的视频需要重新生成。

## 删除

删除项目时，其他项目仍在使用的原件会保留，并移出将被删除的项目目录。对原件执行永久删除，或在文件夹中删除该原件，会清理所有项目中的对应引用。外部复制导入前的原文件不属于工作台管理范围，工作台不会替你删除它。
