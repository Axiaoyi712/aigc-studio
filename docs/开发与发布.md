# 开发与发布

## 目录

- public/：原生 JavaScript、HTML、CSS 界面。
- server.mjs：本机 HTTP 服务、上传、队列与 ComfyUI 通讯。
- projects.mjs、characters.mjs、production.mjs：项目、角色、分镜与一致性检查。
- storage.mjs：正式媒体归档到 ComfyUI/output/AIGC项目，稳定保存版本关联。
- project-files.mjs、根目录 Python 脚本：尾帧、剪辑、项目打包与恢复。
- prompt-library.mjs、assistant.mjs：提示词检索与可选本地文字助手。
- workflows/：五份已适配工作流图；templates 中包含派生模板。
- test/：Node 行为测试和 Python 媒体测试。

## 更新约定

只将源码与通用文档提交。保持 config.json、data/、outputs/、个人提示词库、模型、生成媒体和密钥在 Git 之外。运行前复制两个示例文件；已有配置不要覆盖。公开仓库前应再次审查工作流里的提示词、截图、文档、模型来源和授权。

Node 测试使用隔离临时目录和模拟引擎；Python 测试生成小型测试片段。修改工作流后，还需在目标机器上进行真实首帧和视频生成，核对选中版本、队列恢复、输出路径与项目导入；自动测试无法代替图像质量验证。

## 发布范围

这是单机工作台源码。GitHub 下载不会自动获得当前电脑上的项目、模型、提示词合集或显卡配置。第三方组件与模型按各自来源管理；本仓库尚未授予对全部源码的通用开源许可，由仓库所有者决定后续许可方式。
