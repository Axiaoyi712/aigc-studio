# 单份存储与永久删除

工作台管理的图片、视频、参考素材、驱动片段和成片统一保存在ComfyUI的 `output/AIGC项目/` 下。同一内容按SHA256核对，只保留一个实际文件。项目、角色、作品页和镜头都引用该文件，项目资料中的JSON、文字索引不是另一份图片或视频。

## 删除规则

- “我的作品”的删除和多选删除会永久删除文件，并同步清除所有镜头、素材库及候选版本中的对应引用，不再仅隐藏记录。
- 删除项目会移除项目生成内容、导入的驱动副本、片段与成片。公共素材库中独立保存的参考原件保留；同一生成文件作为参考被引用时，其引用会随文件删除而清理。
- 从统一目录用资源管理器删除文件，工作台空闲时会在数秒内核对并清除对应记录和引用，不会从缓存恢复文件。整个项目目录被删除时，会同步移除该项目记录。
- 正在生成、精修或导出时，先完成或取消队列再删除，避免文件正在使用时产生不完整结果。
- 不同生成版本、AI精修版本、独立成片是不同内容，不能仅因人物相同而当成重复文件删除。

## 避免再次复制

“查看原文件”“打开所在文件夹”均指向唯一原件，不再自动下载另一份到下载目录。视频生成直接引用已确认首帧，不再把它重复上传为缓存。角色、场景和道具跨项目使用时只有索引，不额外复制图片。

工作台不再生成包含媒体的ZIP备份。仍可从已有ZIP恢复项目；解包临时文件处理完成即清理，恢复的相同媒体仍会去重。维护记录只保存操作清单、校验值与配置/JSON资料，不保留媒体副本。

## 管理范围

以上同步适用于工作台管理的统一目录与其引用。你另行用其他软件手动复制、改名导出、上传云盘的文件，工作台无法保证在任意位置自动追踪删除。外部文件夹中的原始素材不由工作台接管。

原件永久删除后，工作台没有媒体回收副本；确认对话框会明确说明。
