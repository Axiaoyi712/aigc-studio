# 项目素材与文件夹同步（v0.9.0）

进入“镜头项目 → 资产定稿”。新项目从空素材库开始，角色、场景、道具、风格按项目分别管理。

## 一次整理，多镜复用

1. 点击“上传素材”，填写人物或场景名称，可一次选择多张图片。选择已有素材组，可以继续补充图片。
2. 同一个人的正面、侧面、全身放在同一角色卡中；场景的全景和局部图也放在同一场景卡中。
3. 点击“查看与定稿”，勾选常用参考，编辑每张图片的用途。备用图可以保留但不勾选。人物身份和服装在同处填写。
4. “分镜设计”中选择出场角色、场景和道具。要逐镜选择场景时，取消“继承项目场景／道具参考”。“沿用上一镜素材”只复制选择，不复制图片。
5. 查看“实际使用”的参考缩略图，再生成首帧。确认首帧版本后生成视频，最后拼接导出。

从素材库选用：可筛选公共素材、其他项目素材、待分类素材。多选后才加入当前项目。从我的作品选用：只显示成功的图片，加入时复用同一原件。

## 原件存放

唯一根目录仍为 ComfyUI 的 `output/AIGC项目`。项目专属参考存入相应项目的角色、场景、道具或风格子目录；同一组下保存多张图片。镜头首帧、视频和成片仍在各自原有目录。

跨项目复用后，原件移动到公共素材库，各项目记录同一文件的引用。相同内容根据校验值去重，不增加媒体备份。旧版未被引用的素材保留在“待分类素材”，不会自动归入新项目。

查看与定稿 → 定位原文件：在资源管理器中选中具体图片。复制路径：复制原件绝对路径。使用情况：查看关联的项目、角色和镜头。

## 直接在文件夹整理

后台约每3秒检查一次，新增或修改的文件需连续检查稳定后才接纳，通常3～6秒反映到工作台。

- 把 PNG、JPG、WebP 图片放进当前项目的“角色／名称”“场景／名称”“道具／名称”“风格／名称”目录，工作台会自动建组或加入对应组。单张最大20MB。
- 改图片文件名，会保留素材编号和既有镜头引用；显示新的文件名与位置。
- 移动图片到另一个项目或分类目录，会同步调整归属；原件仍只保留一份。
- 修改或替换原图片内容，会刷新预览，相关首帧提示重新检查；不会自动重新生成视频。
- 删除原图片，等待短暂检查后，素材和镜头引用一起清理；不会从缓存恢复。
- 改项目文件夹名称，通过项目资料中的稳定编号重新识别。请保留“项目资料/项目记录.json”，不要手动改项目编号。
- “项目文件”显示项目目录实际存在的图片、视频和声音，约3秒刷新。手动放入的视频可在这里查看，不会被伪装成一次生成任务或自动替换选中的视频。
- 生成、排队、精修或导出期间，涉及生成引用的同步延后到队列空闲，避免执行中途改变参考图。

只自动识别上述受管理目录。外部原始文件夹不扫描，不复制或修改外部原片。工作台打开时浏览器自动刷新素材，无需重新启动软件。

## 移出与彻底删除

- 移出本项目：取消该项目及镜头关联，原件保留；项目独享素材转入待分类。
- 彻底删除：删除唯一原件，并同步清理所有项目、角色、镜头和作品的相关引用，不生成媒体备份。
- 删除项目：删除项目专属素材、镜头产物和成片。已被其他项目共用的原件保留在公共素材库。

支持多选合并、移出、彻底删除。操作前可查看使用位置和受影响镜头数量。
